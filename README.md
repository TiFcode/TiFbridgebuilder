# TiFbridgebuilder

Un joc 3D accesibil de construit poduri: unește puncte fixe, creează o șosea susținută de triunghiuri și testează construcția cu un autobuz școlar detaliat.

Rulează ca site static; dependența 3D este Three.js, încărcată ca modul ES din CDN.

## Asset-uri

- Decorul folosește modele PBR și texturi CC0 de la [Poly Haven](https://polyhaven.com/).
- Modelul autobuzului școlar este „SCHOOL BUS” de Kyle Li, disponibil prin [Poly Pizza](https://poly.pizza/m/2_1dZHNPJqJ), sub licența CC BY.
- Sunetul de pornire a motorului și bucla de rulare lentă sunt înregistrări CC0 de pe [OpenGameArt](https://opengameart.org/content/car-engine-start-01) și [OpenGameArt](https://opengameart.org/content/racing-car-engine-sound-loops).
